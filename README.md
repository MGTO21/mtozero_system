# Mtozero Shop — نظام إدارة المخزون والمبيعات

نظام سحابي لمتجر أحذية وملابس في الأبيض، ولاية شمال كردفان. يعمل من الموبايل والديسكتوب،
قابل للتثبيت كتطبيق (PWA)، ويعرض بياناتك حتى لو انقطع الإنترنت.

> **البدء السريع:** اتبع [`docs/SETUP.md`](docs/SETUP.md) خطوة بخطوة.
> **قبل أي تعديل:** اقرأ [`CLAUDE.md`](CLAUDE.md).
> **بعد أي تعديل على البيع أو المخزون:** نفّذ [`docs/TESTING.md`](docs/TESTING.md).

```bash
npm install
cp .env.local.example .env.local   # ثم املأ مفاتيح Firebase
npm run dev
```

## ما الذي يفعله النظام

### 🏷️ تسجيل بيع سريع — أهم شاشة
منتج ← مقاس ← تأكيد. ثلاث نقرات من فتح التطبيق إلى حفظ عملية كاملة.

- تظهر **المقاسات المتوفرة فقط** — لا يمكن بيع مقاس نافذ أصلاً.
- السعر الافتراضي جاهز وقابل للتعديل فوراً (خصم لعميل معيّن) مع بيان قيمة الخصم.
- خصم الكمية من المخزون **داخل Firestore transaction**: لا بيع زائد حتى مع جهازين معاً.
- دين كامل أو دفع جزئي مع اسم ورقم العميل.
- **رسالة فاتورة جاهزة** للنسخ أو الفتح مباشرة في واتساب.

### 📦 المخزون
- عرض بصري لكل مقاس وكميته: المتوفر واضح، والنافذ بإطار متقطّع باهت (**يبقى ظاهراً** لتعرف
  أي مقاس ينقصك بالضبط).
- **فلتر المقاس**: العميل سأل عن 42؟ اضغط 42 وترى كل المتوفر فوراً بدون تفتيش الكراتين.
- بحث فوري بالاسم أو الماركة أو الكود، وفلاتر: أحذية / ملابس / مخزون منخفض / المؤرشف.
- إضافة مقاسات دفعة واحدة عبر مجموعات جاهزة (39–44، S–XXL…).
- رفع صورة للمنتج، و**هامش الربح محسوب تلقائياً** بجانب كل منتج.
- أرشفة بدل الحذف — تاريخ المبيعات يبقى سليماً.

### 📊 لوحة التحكم
مبيعات اليوم بحجم كبير، رسم بياني لآخر 7 أيام، مبيعات الأسبوع، صافي ربح الشهر بعد المصروفات،
الديون المفتوحة، أكثر 5 منتجات مبيعاً، و**تنبيهات على مستوى المقاس** لا المنتج.

### 💵 الديون
كل عميل في سطر واحد بإجمالي ما عليه، وتفصيل عملياته. تسديد جزئي أو كامل بضغطة، مع تحديث
الحالة تلقائياً، وزر تذكير جاهز عبر واتساب.

### 📣 حملات واتساب (المالك فقط)
إرسال العروض ووصول البضاعة الجديدة لعملائك — **مجاناً بالكامل**.

> **الحقيقة أولاً:** واتساب لا يسمح لأي موقع بالإرسال نيابة عنك. الطريق الرسمي (Cloud API) يتقاضى
> ثمن كل رسالة تسويقية ويحتاج رقماً مخصصاً وتوثيق Meta. وأدوات الأتمتة غير الرسمية تُحظر رقمك.
> فالنظام يقوم بالأجزاء المشروعة والمُتعِبة فعلاً، والإرسال يبقى بيدك.

- **شرائح جاهزة**: كل العملاء · اشتروا آخر 30 يوم · انقطعوا 60 يوم · الأكثر إنفاقاً · أصحاب رصيد إحالة
- **قوالب رسائل** مع متغيرات `{الاسم}` و`{المتجر}` و`{الرصيد}` — الرسالة تصل باسم العميل لا كتعميم
- **صورة عرض** بلوغو المتجر وصور المنتجات وأسعارها، تُرفق مع الرسالة (الملابس تُباع بالنظر)
- **الطريق (أ) — القائمة البريدية**: تصدير جهات الاتصال كملف `.vcf` يحفظ كل عملائك دفعة واحدة.
  هذا يحل العقبة الحقيقية: القائمة البريدية لا تصل إلا لمن حفظ رقمك.
- **الطريق (ب) — طابور الإرسال**: يفتح محادثة كل عميل والرسالة جاهزة باسمه، ويتذكر أين وصلت.
  يصل للجميع بلا شروط، ومطابق لشروط واتساب 100%.
- **سجل الحملات** مع استثناء تلقائي لمن راسلته خلال 7 أيام — حتى لا يحظرك عملاؤك

### 🔄 الإرجاع والاستبدال
إرجاع جزئي أو كامل: القطع تعود للمخزون، والربح والمبلغ المستحق يُعاد حسابهما، والعملية
تبقى مسجّلة كـ «مرتجع» ولا تُحذف كأنها لم تحدث.

### 📈 التقارير (المالك فقط)
- فلترة يومي/أسبوعي/شهري/مخصص.
- **حساب الربح كاملاً**: المبيعات − تكلفة البضاعة = الربح الإجمالي − المصروفات = صافي الربح.
- مقارنة الشهر الحالي بالماضي (مبيعات وصافي ربح).
- تقرير **البضاعة الراكدة** — ما لم يُبع منه شيء منذ 30 يوماً فأكثر.
- تصدير Excel/CSV بترميز عربي سليم، ونسخة احتياطية JSON.

### 💸 المصروفات
إيجار، نقل، تغليف… تُخصم تلقائياً من صافي الربح. الحذف للمالك وحده.

### 🕓 سجل النشاط (المالك فقط)
كل بيع وتعديل وأرشفة وتسديد وإرجاع — باسم من قام بها ووقتها. لا يمكن تعديله ولا حذفه.

### 👥 الفريق والصلاحيات
- **المالك**: كل شيء.
- **الموظف**: يبيع ويدير المخزون ويتابع الديون. لا يرى التقارير ولا سجل النشاط، ولا يرى
  هامش الربح إلا إذا فعّلها له المالك.

المنع مطبّق في ثلاث طبقات: إخفاء القوائم، تحويل المسارات، وقواعد أمان Firestore.

### 📱 PWA
تثبيت على الشاشة الرئيسية، فتح كتطبيق مستقل، وضع ليلي افتراضي مع إمكانية التبديل، إشعارات
فورية عند نجاح أو فشل أي عملية، وتصميم mobile-first بالكامل.

## البنية

راجع [`CLAUDE.md`](CLAUDE.md) للتفاصيل. الملفات التي تحدد سلوك النظام:

| الملف | المسؤولية |
|---|---|
| `src/lib/db/sales.ts` | البيع والتسديد والإرجاع — كلها transactions |
| `src/lib/db/products.ts` | المنتجات، الأرشفة، رفع الصور |
| `src/lib/analytics.ts` | كل التجميعات والتقارير |
| `firestore.rules` | الصلاحيات الحقيقية — لا تعتمد على واجهة المستخدم وحدها |
